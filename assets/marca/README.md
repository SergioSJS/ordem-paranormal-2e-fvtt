# Marca

`setup.png` é o card do sistema na tela de setup do Foundry (`media` tipo `setup` no
manifesto). Feito com as fontes e a paleta do próprio sistema (OFL) e o selo da Licença
da Comunidade a 12% da largura — nenhuma arte do livro. Para refazer, o HTML que o gera
está em `scripts/marca/setup.html`; renderize a 1200×675 com o navegador headless
(`node scripts/marca/gerar.mjs`).
